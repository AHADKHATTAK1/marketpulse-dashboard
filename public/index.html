⚙️ How to configure Google Drive Backup?
  1. Go to the Google Cloud Console, create a project, and enable the Google Drive API.
  2. Create a Service Account, create a JSON key, and download it.
  3. Rename the file to credentials.json and place it inside the data/ folder in this project root (a template credentials.json.template is provided there).
  4. Create a new folder in your personal Google Drive, copy the Folder ID from the URL bar, and paste it into the GD_FOLDER_ID variable in your project's .env file.
  5. Crucial: Share that Google Drive folder with the Service Account email address displayed above!
  6. Restart your Express server.
